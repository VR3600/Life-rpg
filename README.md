A gamified habit tracker that translates mundane real-world tasks into an engaging virtual progression system. 

* **Live Deployed URL:** https://life-rpg-rgik.onrender.com
* **Walkthrough Video:** https://drive.google.com/file/d/1GWAcwiqKbNZEAIQIc5EhVZaa4Rx4j_4z/view?usp=sharing

**Core Features**
* User Authentication & Security via Firebase Cloud Firestore.
* Gamified RPG Progression Engine with dynamic XP leveling.
* Streak Combo multipliers (+50% rewards) and Daily Boss Quests.
* Merchant Shop economy to buy digital items (Themes, Badges).
* Highly tactile UI with optimistic updates, audio feedback, and screen-shake mechanics.

**Setup Instructions**
1. Clone this repository to your local machine.
2. Review the `.env.example` file for the required Firebase configuration structure.
3. Open `index.html` in your browser or use an extension like Live Server to run the application.
